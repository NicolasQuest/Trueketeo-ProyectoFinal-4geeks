# Trueketeo - Plataforma de Trueque Digital

Trueketeo es una plataforma donde las personas pueden intercambiar objetos de forma económica, ecológica y sustentable. En un mundo donde todo tiene precio, creamos una alternativa inclusiva: intercambio sin dinero.

Promovemos sostenibilidad y conciencia ecológica, demostrando que existen alternativas al consumo excesivo. Incentivamos intercambiar lo que ya tienes, fortaleciendo redes de ayuda mutua y dando segunda vida a objetos destinados a la basura.

Nuestro proyecto culmina todo lo aprendido: conocimientos técnicos aplicados a un producto con propósito real y orientación al usuario. Nos exigió colaboración profunda, construcción sobre código ajeno y adaptación constante.

---

## Tecnologías usadas

- **Frontend:** React.js, HTML, CSS, Bootstrap  
- **Backend:** Python, Flask, JWT, SQLAlchemy  
- **Base de datos:** PostgreSQL / MySQL / SQLite (configurable)  
- **Herramientas:** Pipenv, Node.js (v20), Webpack  

---

## Características principales

- Sistema de trueque digital para impulsar la economía colaborativa sustentable.  
- Autenticación segura con JWT.  
- API RESTful con Flask.  
- Gestión de base de datos con SQLAlchemy.  
- Uso de variables de entorno para configuración.  
- Fácil despliegue en Render.com y Heroku.  
- Gestión del frontend con React y Bootstrap para interfaz responsiva.
