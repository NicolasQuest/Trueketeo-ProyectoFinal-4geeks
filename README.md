# Trueketeo - Digital Barter Platform

Trueketeo is a platform where people can exchange items in an economical, ecological, and sustainable way. In a world where everything has a price, we created an inclusive alternative: exchanging without money.

We promote sustainability and ecological awareness, showing that alternatives to overconsumption exist. We encourage exchanging what you already have, strengthening mutual aid networks, and giving a second life to items destined for the trash.

Our project culminates everything we’ve learned: technical knowledge applied to a product with a real purpose and user focus. It required deep collaboration, building upon existing code, and constant adaptation.

---

## Technologies Used

- **Frontend:** React.js, HTML, CSS, Bootstrap  
- **Backend:** Python, Flask, JWT, SQLAlchemy  
- **Database:** PostgreSQL / MySQL / SQLite (configurable)  
- **Tools:** Pipenv, Node.js (v20), Webpack  

---

## Main Features

- Digital barter system to promote a sustainable collaborative economy.  
- Secure authentication with JWT.  
- RESTful API with Flask.  
- Database management with SQLAlchemy.  
- Use of environment variables for configuration.  
- Easy deployment on Render.com and Heroku.  
- Frontend managed with React and Bootstrap for a responsive interface.
